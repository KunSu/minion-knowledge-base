# 🔧 你的小红书收藏夹在吃灰吗？

> 来源:小红书 openclaw 收藏夹 · 作者 陈什么夏 · Edited at Mar 30
> 原文存档:[你的小红书收藏夹在吃灰吗.md](../../../raw/2026/07/rednote/你的小红书收藏夹在吃灰吗.md)

## 要点

💫 经常刷到好内容，收藏了一堆，但想找的时候根本记不清在哪条帖子里。小红书的收藏夹基本等于黑洞，收了就忘。

作为一个用 Obsidian 做知识管理的人，我一直想要一个工具：把小红书帖子直接变成我的笔记，而且是那种我 5 秒就能判断"值不值得深读"的笔记，不是原文搬运。

所以我写了一个 Claude Code Skill（开源插件），一行命令安装，粘个链接就能用。

它能做什么✨ ：

- 粘一个小红书链接（网页），自动提取全部内容（文字+图片）

- 视频帖子会自动下载→提取音频→本地 whisper 语音转录

- 输出一条精简笔记：一句话核心洞察+跟我有什么关系+值不值得深挖

详细内容折叠在里面，需要的时候再展开：

🧠 最有意思的部分：它会读 Claude Code 的记忆系统，根据你的背景自动生成"这跟我有什么关系"。

🚀 技术上非常轻量：

不需要 MCP 服务器、不需要无头浏览器

只用 Chrome cookies + 一次 HTTP 请求 + 本地模型

视频转录用的 mlx-whisper，M 系列芯片上飞快

💡 做这个的过程让我意识到：信息过载的问题不在于获取，而在于判断。收藏 100 条帖子容易，但从中提取出对自己真正有用的 3 条才是难点。

开源 Claude Code，一行命令就能装：

🔗 GitHub: https://github.com/chenxiachan/xhs-claude-skills

📖 支持命令：

/xhs 单条提取

/xhs-batch 批量提取

欢迎试用和反馈！
