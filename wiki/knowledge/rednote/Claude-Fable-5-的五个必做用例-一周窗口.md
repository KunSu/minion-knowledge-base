# Claude Fable 5 的五个必做用例：一周窗口

> 来源:小红书 openclaw 收藏夹 · 作者 马丁没有早晨 · Jul 3 上海
> 原文存档:[Claude-Fable-5-的五个必做用例-一周窗口.md](../../../raw/2026/07/rednote/Claude-Fable-5-的五个必做用例-一周窗口.md)

## 要点

你现在如果还只拿 Fable 5 写小脚本，真的有点浪费了。

因为这可能是一个很短的窗口期。

Fable 5 的价格和额度很可能会调整，而真正会用的人，已经不是在问它“帮我写段代码”，而是在用它做五件更狠的事。

第一，克隆你正在付费的软件。

比如语音转文字工具、内容处理工具、自动化工具。

你先让 Opus 做规划，再交给 Fable 5 长时间执行，把原本依赖云端的 SaaS，变成本地可运行的版本。

好处很直接：

数据不出本地，月费也能省下来。

第二，审计你自己的 Claude Code 使用方式。

很多人每天都在用 Claude Code，但从来没有复盘过：

哪些任务可以做成 Skill？ 哪些流程可以自动化？ 哪些提示词其实一直在重复？

Fable 5 可以分析你的历史会话，把你的 AI 工作流重新整理一遍。

这对重度用户非常有价值。

第三，做一个自己的代理操作系统。

不是装个系统，而是把 Claude Code、Skill、自动化、任务面板，包装成一个你自己的图形界面。

你可以把研究、写作、剪辑、销售、财务这些流程全部做成按钮。

点一下，就让 Agent 自己跑。

第四，代码审查。

一个代码库，人工 review 很容易漏问题。

但 Fable 5 可以同时从多个角度检查：

异常处理、安全漏洞、性能问题、架构问题、重复代码。

案例里，它几分钟内就找出了几十个潜在问题。

第五，直接用 PRD 生成软件。

这才是最震撼的地方。

你不只是让它写一个组件，而是给它一份产品需求文档，让它自己拆任务、写代码、提交版本、持续迭代。

案例里，它甚至写出了两万多行 TypeScript 代码。

所以 Fable 5 真正的价值，不是“更聪明的聊天机器人”。

而是一个能长时间执行复杂任务的 AI 工程代理。

但这里有个提醒：

不要一上来就乱跑大任务。

最耗额度的是本地软件克隆和大型 PRD 开发。

更适合先做的是：

审计你的 Claude Code 工作流，或者给现有代码库做一次深度 review。

因为这两个最容易见效，也最不容易浪费额度。

我的判断是：

Fable 5 最适合的人，不是只想要答案的人。

而是已经有工作流、有项目、有重复任务，想把 AI 从“辅助工具”升级成“执行系统”的人。

如果你现在还在手动复制粘贴提示词，那你用到的只是 AI 的表层能力。

真正的机会，是让它开始替你跑完整流程。
