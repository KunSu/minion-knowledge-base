# 和OpenClaw创始人学习怎么一天2000+ Commit

## 要点

Peter Steinberger到底是怎么让Coding Agent如此高效的给他干活的？？我们团队一共5个人，抛去OpenAI / Claude Subscription不说，运行着2个Open Claw Agent，我自己同时跑4个Claude Code Instance，但是单日commit数量还不及Peter的1/10。

今天有空研究了下他过去做Open Claw和其他开源项目的Commit记录，以及他和OpenAI的访谈和几个Anthropic关于AI Coding的对话，发现自己之前用Coding Agent的思路还是非常IC导向，AI只是让我的执行速度变快了，但是并没有让我能够同时管理多个大型项目。

整理了下他的核心技巧。这篇小红书图文是我原本博客英译中+OpenClaw排版的，所以可能语言有些出入，想看原文的可以到chenterry.com上去看。
