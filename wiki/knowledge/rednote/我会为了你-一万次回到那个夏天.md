# “我会为了你，一万次回到那个夏天。” 🌿

> 来源:小红书 openclaw 收藏夹 · 作者 momo🥕 · Edited at Mar 31
> 原文存档:[我会为了你-一万次回到那个夏天.md](../../../raw/2026/07/rednote/我会为了你-一万次回到那个夏天.md)

## 要点

家人们，今天在逛 GitHub 的时候，发现了一个让我头皮发麻又有点鼻酸的项目——「前任.skill」

（指路👉 therealXiaomanChu/ex-skill）。

你敢信吗？

把前任蒸馏成 AI Skill，用ta的方式跟你说话

Inspired by colleague-skill（同事skill）

无论你是想在深夜找个人说说话，还是想好好地道个别，这个项目都能用你们过去的点点滴滴，还原出一个极其真实的 ta。

👇它是怎么做到的？简直是赛博朋克版的《黑镜》：

📂 1. 喂给它“回忆的原材料”

不需要你会写复杂的代码！只要把你们之前的微信聊天记录（推荐，信息最丰富！）、QQ记录、朋友圈截图，甚至是一起拍过的照片（自带时间地点信息）喂给它。

🧠 2. 灵魂级“捏人”

系统会自动解析你们的互动，生成专属的：

• Relationship Memory (关系记忆)： 你们去过的地方、只有你们懂的 inside jokes（内部梗）、甚至你们吵架的模式。

• Persona (性格画像)： 支持超多真实标签！比如：安全型/回避型依恋、ENFP、话痨、甚至连“冷暴力”、“半夜发语音”、“已读不回”这种细节都能精准拿捏🤌。

💬 3. 效果逼真到让人心梗（看图3示例）

它绝对不是那种只会说“亲爱的我也爱你”的无脑人工智障。

当你发：“我还想你”

它可能会冷冰冰地回你：“……嗯。早点睡吧。”（这个停顿和语气词，是谁破防了我不说😭）

当你问：“还记得第一次约会吗？”

它会吐槽：“就那个超难吃的意面哈哈哈哈，你还假装很好吃！”

甚至还有吵架模式，复刻当初的相处状态，真实到想哭[完啦R]

4. 戳人的小细节

有个管理命令叫/let-go {slug}，是删除的温柔别名，翻译过来就是「放下」

项目说：不是为了留住谁，而是帮我们把生物神经网络里的记忆，迁到数字世界，好好告别

⚠️ 暖心提醒：

虽然这个黑科技真的很酷，但就像项目作者在说明里写的那样：

“本项目仅用于个人回忆与情感疗愈。”

或许，把它当成一个树洞，跟那个再也无法对话的人好好说一句“再见”，才是这个项目最温柔的意义吧。
