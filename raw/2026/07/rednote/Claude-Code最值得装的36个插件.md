## 正文

强调：不要都装不要都装越多越慢越多越慢，选你真正需要的
	
darkzodchi从Claude Code市场9000+插件里挑出36个值得装的。
	
官方必装8个：
Frontend Design（400k installs最流行）
Superpowers（290k 瑞士军刀）
Context7（实时文档，解决过时API幻觉）
Code Review / Security Guidance / Commit Commands / Feature Dev / Plugin Toolkit
	
语言服务器 4个：TypeScript / Python / Rust / Ruby，给Claude和VS Code一样的代码智能。
	
高级工具 5个：
Ralph Loop（自治编码session）
Chrome DevTools（前端调试神器）
Playwright（控制真实浏览器）
Firecrawl（爬网页）
Sourcegraph（跨仓库搜索）
	
数据+部署：SQL Analytics / Data Engineering / Amplitude / Vercel / AWS Deploy / PagerDuty Risk Score
	
集成类：GitHub / Slack / Sentry / Linear / Supabase / Stripe / Mintlify
	
Knowledge Work 6个（不只为开发者）：
/plugin marketplace add anthropics/knowledge-work-plugins
Brand Voice / Marketing / Sales / Legal / Finance / Productivity
	
按角色挑3-5个就够：
开发者：Frontend Design + Code Review + Commit + LSP
全栈：Superpowers + Context7 + GitHub + Supabase
前端：Frontend Design + Chrome DevTools + Playwright + Vercel
DevOps：AWS Deploy + Sentry + PagerDuty + GitHub
商业：Brand Voice + Marketing + Sales + Productivity
数据：SQL Analytics + Data Engineering + Firecrawl
	
重点提示：别装全。每个插件都占context。3-5个是sweet spot。不用的用 /plugin disable 禁用。
	
安装：在Claude Code输入 /plugin → Discover → 选装。社区插件先 /plugin marketplace add owner/repo。
