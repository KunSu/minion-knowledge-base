# 人类满分程序员：每天早9点收到架构优化建议

- **来源 board**: openclaw (https://www.rednote.com/board/698ed28d0000000025034bea)
- **URL**: https://www.rednote.com/board/698ed28d0000000025034bea/6a101f9f000000003703448a?xsec_token=ABGuAEpG1Rfn5OOwwuesF9fiLouMXpVEfsmhU_wXxTfJw=&xsec_source=pc_board
- **作者**: 趴在关键词上捡钱
- **日期**: May 22

## 正文

人类满分程序员最近用Claude Code 挂上自己的 SKILL  /improve-codebase-architecture，让 Agent 每天早 9 点定时分析仓库，找架构问题，然后直接开一个GitHub Issue。
	
我的实现方法：
	
 先把 Matt 的推特内容和下面的仓库链接发给 Claude Code。告诉它你也想要（前提你得有一个项目仓库，越烂越好，不然你不知道 Matt 的 SKILL 有多强）
	
 Claude Code 会要求你在网页端claude.ai接入GitHub connector，给仓库授权
	
 Claude Code 读取 Matt 的仓库 issues 告诉你他打的标签是source:architecture-review。
	
 然后等 Claude Code 出餐即可。
	
 设置好以后 Issue格式自动参考 Matt Pocock 的风格：
	
 上半部分是架构分析（问题 + 方案 + Mermaid 图）
	
 下半部分是完整 PRD（User Stories + 实施决策 + 测试方案）
	
 每天一条，不重复，不打扰，打开 GitHub 就能看到
	
如果你持续关注 Matt 就会取关所有 influncer 和 AI Builder，放弃使用 Claude Code 和 OpenAI 官方教程用法。然后你的注意力就收紧了，你就有了更多的时间，你会慢慢听懂 Matt 所有的词汇和工作流程，然后你照着他的方式一步一步搞定自动化。
